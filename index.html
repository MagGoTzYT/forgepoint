Safety model

Safe on machines that matter

Read-only checks need no administrator rights. Anything that changes a system explains what it will do, shows the exact command, says whether it needs elevation, and waits for you.

FORGEPOINT never

  • Disables Windows Defender or the firewall
  • Stops security or core Windows services, or ends critical processes
  • Removes drivers automatically
  • Edits the registry behind your back
  • Runs a downloaded script without you reviewing it
  • Sends your data anywhere

FORGEPOINT always

  • Shows the exact command before a repair runs
  • Asks for a second confirmation on risky scripts
  • Deletes only the temp files it listed, never folders or recent files
  • Saves a safety copy before restoring a database backup
  • Records every action in the activity log
  • Labels anything Windows can't report as unavailable

Questions

Before you install

Does it need administrator rights?

No. Every read-only check runs as a standard user. A few repairs, such as SFC, DISM and driver backup, need elevation; FORGEPOINT marks those clearly and restarts itself as administrator only when you choose to, through the normal Windows prompt.

Does it send any data off the machine?

No. There is no telemetry and no account. The only network traffic is from tests you start yourself, such as ping, DNS lookup and the connection check.

Will it fix things automatically?

Never without you. Each repair explains what it does and shows the exact command first. Risky scripts need an extra confirmation, and security features are never switched off.

Can I manage many machines from one console?

FORGEPOINT works on the machine it is running on. For a fleet, technicians carry the portable edition on a USB drive, and workshop records move between installations as JSON exports.

Where is customer data stored?

In a local SQLite database on the machine running FORGEPOINT, or beside the executable in portable mode. It only stores what a repair desk needs: name and, optionally, phone, email and notes.

What happens when Windows can't report something?

FORGEPOINT says so. Temperatures, SMART counters and battery wear appear only when the hardware and Windows provide them; nothing is estimated or made up.

Why does Windows SmartScreen warn me?

FORGEPOINT is not code-signed yet, so Windows doesn't recognise the publisher. Download only from this page, check the SHA-256 checksum above, then choose More info → Run anyway.
